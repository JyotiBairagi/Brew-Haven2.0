# ☕ Brew Haven

A Full Stack Coffee Shop Management System built using Spring Boot.

## Features

- User Registration/Login
- Admin Dashboard
- Coffee Menu
- Cart System
- GPS Ordering
- Razorpay Payment Gateway
- Download Bill (PDF)
- Order Tracking
- My Orders
- Responsive UI

## Tech Stack

Frontend
- HTML
- CSS
- JavaScript

Backend
- Spring Boot
- Spring MVC
- Spring Data JPA

Database
- MySQL

Payment
- Razorpay

Tools
- IntelliJ IDEA
- Maven
